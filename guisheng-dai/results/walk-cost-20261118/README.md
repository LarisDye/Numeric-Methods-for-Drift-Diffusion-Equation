# 反向随机游走计算开销补充实验

2026-11-18 在本机实际执行，独立于原 E0--E6 实验记录。对应演示文稿中的 3 页：单独改变网格、串并行比较、误差与适用范围。联合细化网格的实验数据与图表保留在本记录中。

## 实验设置

- 方程及初边值沿用 `R/problem.R`：a=0.2，D=0.05，T=0.5，区间 [0,1]，零吸收边界。
- 全部任务只查询 x=1/2，一个查询点分为 16 个逻辑块。此前 E1/E2 的误差实验查询 x=1/8，不能将两组数据直接拼成同一点的精度—耗时曲线。
- 网格实验固定每点 M=16384、OpenMP 两线程。分别扫描 N=64 下的 n=256/512/1024/2048，以及 n=1024 下的 N=8/16/32/64/128。
- 联合细化取 N=16/32/64/128、n=N²/8，保持 Dτ/h²=0.2。所有配置均通过非负转移概率检查。
- 并行比较固定 N=64、n=512、M=65536，比较真正串行 C++ 与 OpenMP 1/2/4/8 线程。
- 串行版从现有 `src/random_walk.cpp` 仅删除 OpenMP 编译插件生成，确认 `_OPENMP=0`；路径循环、CMRG 随机数、R 包装、分块和归约保持一致。没有使用速度和 RNG 调用方式不同的纯 R 参考代码充当加速比基线。
- 本机：Windows 11、Intel Core i7-11800H、8 个物理核/16 个逻辑核、31.74 GiB 内存。CPU 名称和核数由系统注册表与 psutil 查询核实；R/compiler 信息另存。

## 计时与核验

每配置预热和校准批量次数后，执行 9 轮计时，轮转同组配置的执行顺序。批量目标为约 0.2 秒；记录每批耗时、调用次数和平均每调用耗时。图中点/柱为这 9 次观测的中位数，误差棒为 Q1--Q3，**不是置信区间**。

计时覆盖完整 `solve_mc` 调用，包括 R 打包、输入校验、C++ 求解、OpenMP 调用及 R 固定顺序归约。编译、输入与种子准备、预热、GC、核验、日志和磁盘写入均在计时区间外。批内重复相同种子用于测量，不当作独立精度实验；不同轮使用不同种子，同一轮所有线程数共享完全相同的路径。

共 18 个配置、162 次批量计时；221 项检查全部通过，包括实际线程数、串行 CMRG 与 R 路径参照，以及不同线程的估计值、标准误、存活数、实际步数和逐块统计一致。实验阶段约 50.98 秒（包含阶段间核验/写盘，不含启动与编译），不作为单次求解时间。

## 主要结果

| 实验 | 配置变化 | 求解耗时中位数（毫秒） |
|---|---|---|
| 固定 N=64 | n=256 / 512 / 1024 / 2048 | 24.33 / 39.48 / 63.71 / 109.13 |
| 固定 n=1024 | N=8 / 16 / 32 / 64 / 128 | 47.57 / 48.00 / 51.45 / 64.54 / 94.25 |
| n=N²/8 | N=16 / 32 / 64 / 128 | 3.14 / 10.51 / 40.21 / 158.00 |

固定 n 的空间扫描中，平均实际步数仅由约 998 增至 1007，但每步转移概率和分支行为改变，耗时仍增加；没有进行硬件性能剖析，不能将增长直接归因于某一种底层硬件瓶颈。联合细化最后两次 N 翻倍，耗时分别增加约 3.83、3.93 倍。

| 程序 | 耗时中位数（毫秒） | 串行中位数 / 本配置中位数 |
|---|---:|---:|
| C++ 串行，关闭 OpenMP | 311.58 | 1.00 |
| OpenMP 1 线程 | 305.69 | 1.02 |
| OpenMP 2 线程 | 154.12 | 2.02 |
| OpenMP 4 线程 | 80.94 | 3.85 |
| OpenMP 8 线程 | 50.42 | 6.18 |

8 线程效率约 77.2%。略高于理想线的小幅差异限于本次编译与计时观测，不代表一般超线性保证。性能结论限于本机、固定任务与计时口径。
