# 初始函数对漂移扩散求解的影响

本实验比较显式 Euler、隐式 Euler、Crank–Nicolson 和硬约束 PINN。保留旧算例作为基准，新增中央窄峰、近左边界窄峰和中央有限光滑峰。物理设置与局部峰形式来自[团队讲义](../source/漂移扩散方程实验讲义.md)。图表和完整解读见 [Word 实验报告](report/更换初始函数后的漂移扩散求解比较.docx)。

## 四个函数如何比较

方程为 `u_t = 0.2 u_x + 0.05 u_xx`，区间 [0,1]，两端始终为零，终止时刻 T = 0.5。有限差分和 PINN 对每个案例读取相同的连续初值或其在求解网格上的采样。

| 标识 | 初始函数 |
|---|---|
| baseline | 保留原始函数 exp(−2x) sin(πx)，最大值 A ≈ 0.44520835。 |
| center | 项目讲义式（4）的中央局部峰。x³(1−x)³ exp[−((x−c)/0.08)²]，c = 0.5，乘常数使最大值等于 A。 |
| near | 同式取 c = 0.2，再独立调到同一峰高。受多项式因子影响，最大值位置约为 0.22939。 |
| compact | A·max(1−((x−0.5)/w)², 0)³。w ≈ 0.14127237，令其半高全宽与中央窄峰相同（约 0.12833）。接点处一、二阶导数连续，三阶导数跳变；支撑区外为零。 |

三个新函数统一峰高，以控制信号尺度。近边界峰的偏斜及宽度随 c 略有变化。两种中央峰的尾部、支撑范围和高阶光滑性也有差别。完整精度的系数在 [参照设置](results/reference/settings.json) 中。

在 65 个公共位置 x = j/64 上记录初态和 t = 1/32、1/8、1/2 的解。两端单列检查，误差只取 63 个内部点。每个时刻的 RMSE 是误差平方均值的平方根；相对 RMSE 是该值除以同一时刻参考解的均方根。参考解在有限区间的加权正弦基上计算，另与镜像热核积分核对；训练只使用初值及方程。

四个初值均非负，真解应在区间内保持非负。评分时直接检查原始预测，每次求解、每个时刻记录内部最小值 `interior_min` 和小于 −10⁻⁸ 的内部点数 `negative_nodes`。这个绝对容差用于排除舍入量级的扰动，所有误差均使用未经裁切的预测值。汇总表中的 `interior_min` 取各次运行的最低值，`negative_runs` 统计出现至少一个低于阈值节点的运行次数，`negative_nodes_min` 和 `negative_nodes_max` 给出该点数在各次运行中的范围。每个差分配置只有一个确定性结果，每个 PINN 配置有三次初始化。

在 t = 1/32 的 63 个内部点上，三个新初值的九次 PINN 训练都出现了低于 −10⁻⁸ 的预测。中央窄峰最低为 −0.007161，近左边界窄峰最低为 −0.003143，中央有限光滑峰最低为 −0.001358。原基准的三个 PINN 以及两档网格上的所有差分格式在全部评价时刻均通过这一检查。该检查只描述所采样的位置和时刻。

## 重现实验

从本目录执行。需要支持 C++11 的编译器、R 和 Rcpp（在 R 中运行 `install.packages("Rcpp")` 可安装），以及 Python、NumPy、SciPy、pandas、PyTorch、Matplotlib；测试使用 pytest。若要重现报告图的字体，系统需能使用宋体和 Times New Roman。

```sh
python -m pip install numpy scipy pandas torch matplotlib pytest
python scripts/make_reference.py
python -m pytest -q tests
python scripts/run_pinn.py
Rscript --vanilla scripts/run_fd.R
python scripts/compare.py
python scripts/plot_results.py
```

两组求解依次运行以减少计时干扰。Python 入口负责生成参照、训练 PINN、核验和绘图，R 调用原方法三的单线程 Rcpp 核心。Apple M3 上运行全部 12 个 PINN 的训练、评价及保存共用约 82 秒。重跑后可直接从原始预测重算各项指标。Word 保留本轮实验结果，脚本重跑时会更新数据和图。

## 预算与计时

- 有限差分沿用方法三的三个时间推进格式。主比较取 N = 64 段、256 个时间步；加密取 N = 128 段、1024 步，仍在相同的 63 个位置评分。三个正时间都落在两套网格的时间层上。每个快照按同一步长从初值推进。计时只测一次从零到终态的完整求解，包含 C++ 工作区及需要的三对角分解，排除 R 调用开销、编译、输入采样和文件读写。每组预热后做九轮批计时，取单次求解耗时的中位数。
- 每次换函数都从头训练原方法四的硬约束网络。两层、每层 32 个 tanh 单元，1024 个固定内部配点，配点种子 2026。初始化种子为 7、17、27。先用 Adam 训练 2000 步，学习率 0.001，再做至多 400 次全批量 L-BFGS 迭代。双精度、单线程 CPU。PINN 误差在每个种子上单独计算，再汇总为中位数和范围。训练和查询分别计时；一次查询预测终态包括两端的 65 个位置，预热三次再计时七次。准备开销和单个模型的总时间另存于原始记录。
- 硬约束输出为 U(x,t) = f(x) + (t/T)·4x(1−x)·F(x,t/T)。新函数从公共定义传入，方程残差对整个 U 自动求导。可用 `scripts/run_pinn.py` 中的 `load_model(path)` 加载 `results/pinn/<case>_seed<seed>.pt`，再传入两列双精度物理坐标 (x,t) 查询。

## 工作分工与工具使用

本部分负责人提出在方法内比较后开展跨方法比较，并通过更换初始函数研究算法表现，重点追问函数光滑度是否影响有限差分精度。团队讲义提供共同物理设置与局部峰形式，具体的归一化、半高宽匹配和评价时刻在后续实现中细化。

使用 Codex 辅助细化实验、生成和修改代码、运行检查、分析结果及整理图表文稿。参考解通过两套独立计算和加密检查核验，方法误差可从保存的逐点预测复算，并另查内部负值。不同初值同时改变了部分形状特征，因此结论限定在本实验的函数与计算预算内。
