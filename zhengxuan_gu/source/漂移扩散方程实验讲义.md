## 第一章　先把问题和边界说清楚

### 1.1 正式模型

在固定区间 $0<x<1$ 上求解

$$
\boxed{
\begin{cases}
u_t=a u_x+D u_{xx}, &0<x<1,\quad 0<t\le T,\\
u(x,0)=f(x), &0\le x\le1,\\
u(0,t)=0,\qquad u(1,t)=0, &0\le t\le T.
\end{cases}}
\tag{1}
$$

其中 $D=\sigma^2>0$。两端固定为零，称为齐次 Dirichlet 边界。可以把它理解成两端始终维持零温度，或到达边界后被移除的信号/物质。

“普通边界”仍需指定具体规则。本讲义选择固定零边界，便于将不同方法的实现统一起来。固定非零值、绝热边界和反射边界是另外的问题，不能随意混用。

本项目需要回答两个问题：求解器是否实现了同一个初边值问题；在达到相同精度时，哪种计算方式更适合当前任务规模。

### 1.2 漂移、扩散与边界各自做什么

漂移改变信号的位置，扩散使信号变平滑，固定零边界使信号能够从区间两端流失。

注意符号：对实线上的纯漂移方程 $u_t=a u_x$，解为 $f(x+at)$，因此 $a>0$ 对应曲线向左移动。有限区间中还受到边界影响，不能将整体平移公式直接当作解。

对于非负初值，正确的吸收边界解应保持非负，最大值不增大，总量通常逐渐减少。**这里不要求质量守恒，也不要求非零常数初值保持不变。** 后两项是旧边界设置下的检查方式，不能继续沿用。

### 1.3 网格包含两个真实端点

将区间分为 $N$ 个小区间：

$$
h=1/N,\qquad x_j=jh,\qquad j=0,1,\ldots,N.
$$

数组长度为 $N+1$。其中：

- `U[0]` 与 `U[N]` 是边界节点，始终赋值为零。
- `U[1:N]` 是 $N-1$ 个待计算的内部节点。
- $n$ 是总时间步数，$\tau=T/n$。
- $U_j^m$ 近似 $u(x_j,m\tau)$。

左右端点彼此独立。代码不对空间索引取模，也不把右端数据接到左端。使用 `np.roll` 时尤其容易意外引入环绕，本方案的基础实现采用明确的切片。

### 1.4 一个容易核验的基准

主实验取

$$
a=0.2,\qquad D=0.05,\qquad T=0.5,
\qquad f(x)=e^{-2x}\sin(\pi x).
\tag{2}
$$

初值在两端为零，区间内部非负。它与边界条件相容，适合用于收敛实验。

旧初值 $\sin(2\pi x)+0.4\cos(6\pi x)$ 的两个端点都等于 $0.4$，不能直接用作这个零边界问题的光滑基准。

## 第二章　用一个简单解析解检查程序

### 2.1 直接代入验证，不展开一般解法

令

$$
\beta=\frac{a}{2D},\qquad
\lambda=D\pi^2+\frac{a^2}{4D}.
$$

选取

$$
\boxed{
u_\star(x,t)=e^{-\beta x}\sin(\pi x)e^{-\lambda t},
\qquad f(x)=e^{-\beta x}\sin(\pi x).
}
\tag{3}
$$

检查边界与初值只需代入 $x=0,1$ 和 $t=0$。检查 PDE 也只需计算一次导数。对 $f=e^{-\beta x}\sin(\pi x)$，

$$
f'=e^{-\beta x}\bigl(\pi\cos(\pi x)-\beta\sin(\pi x)\bigr),
$$

$$
f''=e^{-\beta x}\bigl((\beta^2-\pi^2)\sin(\pi x)
-2\beta\pi\cos(\pi x)\bigr).
$$

因为 $2D\beta=a$，余弦项相消，得到 $af'+Df''=-\lambda f$，正好等于式（3）的时间导数。

对主参数，$\beta=2$、$\lambda\approx0.69348$，到 $T=0.5$ 时整体振幅保留约 $70.7\%$。

这个特制初值只改变幅度，峰的位置不变。它适合验证正确性和收敛阶；观察一般信号的漂移与边界吸收，需要另设局部峰实验。

### 2.2 区分“精确基准”和“一般输入”

基础实验全部先用式（3），使误差可以直接计算。求解器只接收初值和模型参数，解析终态由独立的验证步骤计算。

边界现象实验另采用局部峰，例如

$$
f_{x_c}(x)=x^3(1-x)^3\exp\left[-\frac{(x-x_c)^2}{0.08^2}\right],
\qquad x_c=0.2\ \text{或}\ 0.5.
\tag{4}
$$

该初值和前两阶导数在端点为零。它不必有简单解析解，可用经过网格加密检查的高分辨率隐式差分作为数值参照。

改变 $a,D$ 研究物理效应时，应固定同一个初值。式（3）的基准初值本身依赖 $a,D$；若随参数同步改变它，就无法将结果差异全部归因于漂移或扩散。

## 第三章　有限差分与边界数组

### 3.1 从导数到三点更新

对内部节点，用中心差分近似

$$
u_x(x_j,t)\approx\frac{U_{j+1}-U_{j-1}}{2h},\qquad
u_{xx}(x_j,t)\approx\frac{U_{j+1}-2U_j+U_{j-1}}{h^2}.
$$

它们可由 $u(x_j\pm h)$ 的 Taylor 展开相减、相加得到，空间误差为 $O(h^2)$。

再用向前 Euler 近似时间导数，记

$$
r=\frac{D\tau}{h^2},\qquad b=\frac{a\tau}{2h},
\qquad p_-=r-b,\quad p_0=1-2r,\quad p_+=r+b,
$$

得到

$$
\boxed{U_j^{m+1}=p_-U_{j-1}^m+p_0U_j^m+p_+U_{j+1}^m,
\qquad j=1,\ldots,N-1.}
\tag{5}
$$

式（5）只更新内部节点，两个端点每一步都按边界条件重新赋值。

### 3.2 稳定、单调的基础设置

本项目统一使用容易检查的充分条件

$$
\boxed{r\le\frac12,\qquad |a|h\le2D.}
\tag{6}
$$

这保证三个系数非负且和为 $1$。新内部值是旧邻点值的加权平均，因此不会无端放大最大值，也可以解释为随机游走概率。

这是一组充分的单调性条件，不是所有数值稳定情形的必要条件。本项目不需要进一步分类。若第二个条件不满足，应加密空间网格；只减小时间步长无法修复它。

建议先取

$$
n_0(N)=\max\left(1,\left\lceil\frac{TDN^2}{0.4}\right\rceil\right),
\qquad\tau=T/n_0.
\tag{7}
$$

这样 $r\le0.4$，仍须检查空间条件。主参数的常用网格均满足要求。

### 3.3 可独立运行的显式参考实现

下面的 Python 例子不依赖旧版周期求解器。可以在独立文件中运行，也可以作为自己实现的核验版本。

```python
import numpy as np

def initial(x, a=0.2, D=0.05):
    return np.exp(-a * x / (2 * D)) * np.sin(np.pi * x)

def exact(x, t, a=0.2, D=0.05):
    decay = D * np.pi**2 + a*a / (4 * D)
    return initial(x, a, D) * np.exp(-decay * t)

def explicit(f_grid, a, D, T, n):
    N = len(f_grid) - 1
    h, dt = 1.0 / N, T / n
    r, b = D * dt / h**2, a * dt / (2 * h)
    if r > 0.5 + 1e-14 or abs(a) * h > 2 * D + 1e-14:
        raise ValueError("Refine the grid or shorten the time step")
    old = np.array(f_grid, dtype=float, copy=True)
    old[0] = old[-1] = 0.0
    new = np.empty_like(old)
    for _ in range(n):
        new[1:-1] = ((r-b) * old[:-2] + (1-2*r) * old[1:-1]
                     + (r+b) * old[2:])
        new[0] = new[-1] = 0.0
        old, new = new, old
    return old

N, a, D, T = 64, 0.2, 0.05, 0.5
x = np.linspace(0.0, 1.0, N + 1)
n = max(1, int(np.ceil(T * D * N*N / 0.4)))
u = explicit(initial(x, a, D), a, D, T, n)
truth = exact(x, T, a, D)
print("interior RMSE:", np.sqrt(np.mean((u[1:-1]-truth[1:-1])**2)))
print("boundary error:", max(abs(u[0]), abs(u[-1])))
```

需要自己解释的编程细节包括：为什么数组长度是 $N+1$；为什么切片长度相同；为什么不能从左到右原地覆盖；为什么每一步都设置端点；为什么误差主要在内部节点统计。

### 3.4 用三点卷积实现同一个算法

式（5）本来就是一个局部模板，因此可以比较四种实现：逐点循环、NumPy 切片、卷积函数、Rcpp 双缓冲循环。

注意 `np.convolve` 会反转核。若希望实现式（5），可写成

```python
# old has length N+1; p_minus, p_zero, p_plus are the weights in (5).
kernel = np.array([p_plus, p_zero, p_minus])
new = np.convolve(old, kernel, mode="same")
new[0] = new[-1] = 0.0
```

先用非对称权重的小例子核对方向，再计时。卷积后重设端点是必要操作，不能让卷积函数计算出来的端点值参与下一步。

这四种实现属于同一个数值方法，理论误差相同。它们之间的差异主要来自循环、内存访问、临时数组和库函数开销，适合计算机课程的实现比较。

### 3.5 隐式差分：矩阵首末行怎样处理

将空间导数放在新时刻，得到

$$
\boxed{-p_-U_{j-1}^{m+1}+(1+2r)U_j^{m+1}
-p_+U_{j+1}^{m+1}=U_j^m.}
\tag{8}
$$

只将内部未知量组成向量 $\boldsymbol U=(U_1,\ldots,U_{N-1})^\top$，线性系统为

$$
A\boldsymbol U^{m+1}=\boldsymbol U^m,
\qquad
A=\operatorname{tridiag}(-p_-,1+2r,-p_+).
\tag{9}
$$

$A$ 是 $(N-1)\times(N-1)$ 的普通三对角矩阵。第一行没有左侧内部未知量，最后一行没有右侧内部未知量；矩阵的左下角与右上角不相连。

零边界的贡献为零，所以右端无需加项。若以后改成 $u(0,t)=g_L(t)$、$u(1,t)=g_R(t)$，隐式法右端应分别加入

$$
p_-g_L(t_{m+1})\quad\text{和}\quad p_+g_R(t_{m+1}).
\tag{10}
$$

显式法则读取当前时刻 $t_m$ 的边界值。这一时间层区别应作为编程检查，而不是交给求解器猜测。

常系数和固定步长下，矩阵只装配、分解一次，随后每步回代。不要每步重新分解，也不要显式求逆。主参数的矩阵不对称，可使用 SciPy `splu` 或 RcppEigen `SparseLU`。

```text
创建长度 N-1 的内部向量
装配三条对角线，构造稀疏矩阵 A
分解 A 一次
重复 n 次：用已有分解解线性系统
将内部结果放回长度 N+1 的数组，两端赋值为零
```

在满足 $|a|h\le2D$ 的空间单调性条件时，隐式更新对任意正时间步长稳定且保持非负。但稳定不代表准确，过大的时间步长仍会使结果失真。

### 3.6 理论预测保留到什么程度

对当前光滑解析基准，两种 Euler 方法在稳定设置下都有

$$
\boxed{\text{终态误差}=O(\tau+h^2).}
\tag{11}
$$

因此，沿 $\tau\propto h^2$ 加密网格时，$h$ 减半应使误差大致缩小四倍；固定空间网格、单独缩短时间步长，最终会遇到空间误差平台。总误差还可能出现抵消，不必严格单调。

本项目只要求用这些预测设计实验，不要求推导一般稳定性理论或完整误差定理。

## 第四章　吸收随机游走：边界必须沿路径检查

### 4.1 三个系数就是一步移动概率

当式（6）成立时，$p_-,p_0,p_+$ 都非负且和为 $1$。从一个内部网格点出发，每一步：

- 以概率 $p_-$ 向左移动一格。
- 以概率 $p_0$ 留在原地。
- 以概率 $p_+$ 向右移动一格。

式（5）表示：对下一步可能到达的位置上的旧函数值取平均。重复这个过程，就得到显式差分解的随机表示。

这里仍然从查询点向右偏移更多，而 $a>0$ 时解曲线整体趋向左移。这是“去哪里读取初值”的后向计算，不是直接统计向右移动粒子的密度。

### 4.2 触边后怎样计算一条路径的贡献

从查询节点 $j$ 开始游走。若在任意一步走到 $0$ 或 $N$，立即停止该路径，贡献记为零；若一直存活到第 $n$ 步，则贡献为终点上的初值 $f(X_n)$。

```text
输入：查询节点 j、总路径数 M、总步数 n、三个移动概率
若 j 已经是 0 或 N，直接返回 0
总贡献 = 0
重复 M 条路径：
    当前节点 = j
    重复最多 n 步：
        按三个概率移动一格或停留
        如果当前节点为 0 或 N：
            本条贡献 = 0；终止本条路径
    如果完成 n 步仍在内部：
        本条贡献 = 初值数组[当前节点]
    将本条贡献加入总贡献
估计值 = 总贡献 / M
```

吸收路径也属于抽样结果，所以平均分母必须是全部 $M$ 条路径，不能改成幸存路径数。后一种写法会估计“在幸存条件下的平均”，求的是另一个量。

不取模，不反弹，不将出界路径重新放回区间。最近邻步长保证路径先到端点再离开，因此在 $0,N$ 上即可检查吸收。

### 4.3 为什么不能继续只生成终点

两条路径可能有同一个终点，但其中一条曾经到达边界，另一条始终留在内部。对于吸收问题，它们的贡献不同。

因此，旧方案中“用多项分布一次生成累计位移”的快捷方式不能直接使用；只抽一个连续高斯终点也不能判断中途触边情况。基础实现必须保留逐步检查。

如果后来改用连续高斯步长模拟路径，仅在离散时刻检查是否出界，也可能漏掉两次检查之间的越界。它需要额外的边界误差分析，本项目不把它列入必做内容。

### 4.4 分清抽样误差和差分误差

设单条路径的贡献为 $Y$。吸收规则与式（5）的零边界更新完全对应，所以

$$
\mathbb EY=U_{j,\mathrm{FE}}^n.
$$

用 $M$ 条独立路径取平均，得到 $\widehat u_M$。相对连续解析解的均方误差为

$$
\boxed{
\mathbb E(\widehat u_M-u_\star)^2
=\underbrace{(U_{j,\mathrm{FE}}^n-u_\star)^2}_{\text{离散偏差平方}}
+\underbrace{\operatorname{Var}(Y)/M}_{\text{抽样方差}}.
}
\tag{12}
$$

解释只需两句话：增加路径数降低抽样误差；加密网格和时间步才能改善离散偏差。

实验同时画两种误差：MC 相对同网格显式解的误差，以及 MC 相对连续真值的误差。前者应近似按 $M^{-1/2}$ 衰减，后者最终可能出现平台。

还可以用同一个吸收差分程序推进 $f^2$，估算理论方差：

$$
v_j=\bigl(P^n(f_h^2)\bigr)_j-\bigl(P^nf_h\bigr)_j^2.
$$

这里 $P$ 是一次显式更新，不需要构造新数学模型。这一项属于选做核验，基础实验可以直接从独立路径贡献估计方差。

### 4.5 并行的编程重点

不同路径相互独立，适合按路径块分配到 R 多进程或 C++ OpenMP。每块返回贡献和、贡献平方和、路径数与存活数，主进程按固定顺序归约。

将随机流绑定“重复编号、逻辑块编号”，而不是绑定工作进程编号，便于在改变并行度时重用同一组随机任务。R 可使用 L'Ecuyer-CMRG 的独立流；OpenMP 中应为各逻辑任务使用独立的 C++ 随机数生成器，避免在线程间共享一个有状态生成器。

吸收还带来新的性能问题：边界附近的路径往往提前终止，实际步数不同，任务块可能负载不均。应记录平均实际步数和存活比例，解释并行收益，而不只比较路径总数。

## 第五章　PINN：把初值和边界一起交给网络

### 5.1 网络近似一个什么函数

用神经网络 $U_\theta(x,t)$ 近似整个时空解。它接收空间和时间坐标，输出一个标量。参数 $\theta$ 包括各层权重和偏置。

训练不使用解析终态标签，而是在若干位置检查 PDE、初值和边界是否成立。解析解只用于训练结束后的测试。

基础网络直接输入 $(x,t/T)$，采用平滑的 `tanh` 激活。例如可从两个宽度为 $32$ 的隐藏层开始，使用 PyTorch 自动微分。无需构造周期特征。

### 5.2 软约束：显式加入边界损失

定义物理残差

$$
\mathcal R=U_t-aU_x-DU_{xx}.
$$

分别在内部点、初值点、边界时间点计算

$$
\mathcal L_r=\operatorname{mean}|\mathcal R(x_i,t_i)|^2,
\qquad
\mathcal L_0=\operatorname{mean}|U(y_j,0)-f(y_j)|^2,
$$

$$
\mathcal L_b=\frac{1}{2N_b}\sum_{k=1}^{N_b}
\bigl(|U(0,t_k)|^2+|U(1,t_k)|^2\bigr),
$$

$$
\boxed{\mathcal L=\mathcal L_r+\lambda_0\mathcal L_0+\lambda_b\mathcal L_b.}
\tag{13}
$$

基础权重可先取 $\lambda_0=\lambda_b=1$。边界需要在多个时刻训练，而不是只给出两个空间端点各一次。

### 5.3 硬约束：从函数构造上固定初边值

对本讲义满足 $f(0)=f(1)=0$ 的初值，可构造

$$
\boxed{
U_\theta(x,t)=f(x)+\frac{t}{T}\,4x(1-x)F_\theta(x,t/T).
}
\tag{14}
$$

$t=0$ 时第二项为零；$x=0,1$ 时第二项也为零，因此同时满足初值与两端零边界。

这个版本只需训练 PDE 残差，初值和边界误差仍要独立检查。软约束和硬约束是两种可比较的实现，不必预先认定哪一种训练得更好。

自动微分必须作用于完整的 $U_\theta$，不能只对 $F_\theta$ 求导。若网络内部将 $t$ 除以 $T$，对原始物理时间 $t$ 自动求导即可自然处理链式法则；若手工对归一化时间求导，则必须补上 $1/T$。

### 5.4 学生需要实现的训练循环

```text
生成内部配点、初值点和边界时间点
初始化网络
每一步优化：
    在内部点计算 U
    自动求导得到 U_t、U_x、U_xx
    组成 PDE 残差损失
    软约束时再加入初值和边界损失
    反向传播，更新参数
训练结束后：
    用独立坐标计算初值误差、边界误差、残差和解误差
    保存模型参数、测试预测场和训练损失分项
```

`tanh` 有平滑二阶导数，适合这里的强形式残差；基础实现不使用分段线性的 ReLU。用自动微分求坐标导数时保留计算图，才能继续对网络参数反向传播。

### 5.5 验证不能只看训练损失

零函数虽然满足方程和零边界，却不满足非零初值。因此，即使 PDE 损失很小，也可能没有学到正确解。

至少分别报告：独立初值 RMSE、覆盖整个 $[0,T]$ 的测试时刻上的边界最大误差、留出内部点的残差 RMS、终态内部 RMSE 和时空内部 RMSE。

基础对照可使用固定配点、三个初始化种子。先保持结构与优化器一致，比较软、硬约束；再选择配点数或边界损失权重中的一个因素做消融。

网络表示的是一个固定初值和固定参数下的解。更换初值通常需要重新训练，训练成本必须计入对应任务。

## 第六章　实验：先检查边界，再比较算法

每项实验按“问题、操作、图形、解释”进行。先写下预期，再运行程序；不符合预期的结果也应保留。

### 实验一：边界和索引是否写对

**问题：** 程序计算的究竟是不是式（1）？

**操作：**

1. 用全零初值检查差分、卷积和随机游走，输出应仍为零；PINN 在有限训练后检查其接近零的误差，不要求精确等于零。
2. 对非负初值检查边界始终为零，内部没有明显负值，最大值不出现无故增长。
3. 手算一次小网格更新：取 $N=4,\tau=0.1,a=0.2,D=0.05$，得到 $p_-=0.04,p_0=0.84,p_+=0.12$。
4. 给定数组 $[0,1,0,0,0]$，一次显式更新应得到 $[0,0.84,0.04,0,0]$。分别核对循环、切片和卷积实现。
5. 同一设置下，隐式内部矩阵的主对角线为 $1.16$，下对角线为 $-0.04$，上对角线为 $-0.12$。核对第一行和最后一行，并检查线性求解残差。
6. 随机游走分别从靠近两端的节点出发，确认第一次到达边界就停止，且吸收路径贡献为零。

**图形与记录：** 画初值和一步结果；保存小矩阵与预期数组。将这些检查做成少量可重复的小测试。

**解释：** 只检查最终曲线“看起来平滑”不足以验证正确性。核方向反了、末端环绕了、原地覆盖了，都可能画出平滑但错误的曲线。

### 实验二：差分精度怎样随网格改变

**问题：** 二阶空间差分和一阶时间推进是否给出预期的整体收敛趋势？

**固定条件：** 使用式（3）的解析基准和主参数。

**操作：**

1. 取 $N=16,32,64,128$，预算允许时加 $256$。
2. 每个网格取式（7）的 $n_0(N)$，分别运行显式和隐式法。
3. 对内部节点计算终态 RMSE 与最大误差，边界误差单独记录。
4. 对相邻网格计算 $p=\log_2(E_h/E_{h/2})$。
5. 固定一个网格，再取 $n=n_0,2n_0,4n_0,8n_0$，观察缩短时间步长后总误差如何变化。
6. 对隐式法额外尝试较大的时间步长，区分“程序不发散”和“结果准确”。

**图形：** 误差对 $h$ 的双对数图，附斜率 $2$ 的参考线；固定网格时误差对 $\tau$ 的图；记录时间步数和总耗时。

**解释：** 在光滑基准和足够细网格下，$\tau\propto h^2$ 时观测阶应接近 $2$。固定网格减小 $\tau$ 后，空间误差不会消失。若总误差暂时上升，可能是两类误差抵消发生变化，不能仅凭这一点认定程序错误。

基础项目不必继续分解全部误差。若希望单独测时间阶，可用同一空间网格、经过继续减半验证的极小时间步结果作参照，并说明参照本身仍有数值误差。

### 实验三：同一个模板，哪种实现更省时

**问题：** 循环、切片、卷积和 Rcpp 的差异来自哪里？稀疏求解的主要成本在哪一步？

**操作：**

1. 固定相同 $f_h,N,n$，分别实现显式逐点循环、NumPy 切片和三点卷积。
2. 用 R 向量化与 Rcpp 双缓冲实现同一个公式。语言间比较前，确认步数、精度和输入完全一致。
3. 先核对完整结果一致到合理浮点误差，再进行计时。
4. 扫描 $N=32,64,128,256$；较大规模只在预算允许时运行。
5. 用 RcppEigen 实现隐式内部三对角矩阵，分开记录装配、一次分解和全部时间步回代。
6. 记录数组大小、矩阵非零元数量、因子存储量。若报告峰值内存，注明是否包括进程和工作区。

**图形：** 各显式实现的总耗时对 $N$；隐式法分阶段耗时；可选增加小规模稠密存储与稀疏存储对比。

**解释：** 三点卷积的核很短，调用库函数未必比简单切片快；每步分配临时数组也可能抵消底层实现优势。Rcpp 是否更快应由实测回答，不能仅由语言名称推断。

这一实验比较的是同算法实现。显式和隐式所需步数可能不同，它们之间的最终效率比较应放到同精度实验中。

### 实验四：吸收、样本量与随机误差

**问题：** 正确处理触边后，Monte Carlo 是否仍对应显式差分？增加路径数能解决哪些误差？

**固定条件：** 主参数；先取 $N=8,n=8$，再取 $N=16,n=32$，都查询 $x=1/8$。这组配置取 $r=0.2$，有意使用较粗网格，让有限样本预算下的偏差平台更容易观察。

**操作：**

1. 用显式差分计算相同网格、相同步数下的 $U_{j,\mathrm{FE}}^n$，同时计算解析真值；可复用 $f^2$ 推进得到方差 $v$，检查交叉样本量 $v/B^2$ 是否落在预算范围，其中 $B$ 是离散偏差。
2. 对 $M=256,1024,4096,16384,65536$ 分别独立运行 $30$ 批；先用少量批次检查流程。
3. 对每批保存估计值、存活数和实际执行步数。
4. 分别计算相对显式解与相对解析解的 RMSE。先对各批平方误差取平均，再开方。
5. 换不同起点，画存活比例随起点位置的变化。
6. 作一个明确标记的错误对照：将总贡献除以幸存数。观察它与正确结果的差异，不让它进入正式效率排名。

**图形：** 两种 RMSE 对 $M$ 的双对数图，附 $M^{-1/2}$ 参考线；存活比例和平均路径长度对起点的图。

**解释：** 相对显式解的误差应随抽样量下降；相对连续解的误差最终可能受离散偏差限制。细网格应改善偏差平台。靠近边界时存活少、路径短，不代表可以丢掉这些零贡献样本。

若预算远小于 $v/B^2$，没有观察到平台是正常现象，应报告当前范围主要验证了抽样误差规律。理论平台可以叠加到图上，不能将尚未观测到的平台写成实测结论。

给误差条时，以独立运行的一整批为单位重抽样；不要把一条模拟曲线上的相关节点当作独立重复。

### 实验五：忽略边界会产生什么后果

**问题：** 为什么“区间外补零后做一次高斯卷积”仍不是吸收边界解？

**对照计算：** 将初值在区间外补零，然后计算

$$
u_G(x,T)=\int_0^1 f(y)
\frac{\exp\bigl(-(y-x-aT)^2/(4DT)\bigr)}{\sqrt{4\pi DT}}\,dy.
\tag{15}
$$

这是实线上零延拓初值的解。它只考虑终点落在何处，没有排除中途碰到边界后又返回的路径。因此通常不满足本问题的固定零边界。

**操作：**

1. 先用解析基准，比较 $u_G$ 与 $u_\star$，尤其观察端点和近边界区域。
2. 再用式（4）的两种局部峰，保持各自初值在所有方法中一致。
3. 用高分辨率隐式法建立参照，例如先比较 $N=512,1024$，同时减小时间步；继续加密后结论不变，再将其作为数值参照。
4. 数值积分计算式（15），也要加密求积网格，确认图中差异不是求积太粗造成的。
5. 比较边界附近与区间中部的误差；可改变时间，观察边界影响怎样扩展。

**图形：** 初值、吸收解和无边界高斯解的叠加图；误差随位置的图；非负信号质量保留比 $\mathcal M(t)/\mathcal M(0)$ 随时间的图。两个局部峰的初始幅度不同，跨初值比较采用保留比，或先用同一个高精度积分规则将各初值归一化至相同总量，并在所有方法中使用一致的归一化函数。

**解释：** 远离边界、时间较短时，高斯解可能是有用的局部近似；接近边界或时间增长后，这种近似可能失效。把最终两个端点强行设零，仍不能修正内部已经算错的值。

不必为保留高斯卷积而推导复杂的有界区间核。此实验的价值在于认识边界会改变算法，而不是再增加一种精确解法。

### 实验六：PINN 是否学到了边界

**问题：** 加入边界损失或硬约束后，网络能否同时满足方程、初值和边界？

**建议起点：** 两层宽度 $32$ 的 `tanh` 网络；内部配点 $1024$ 个、初值点 $128$ 个、每端边界时间点 $64$ 个；CPU、双精度。先用 Adam、学习率 $10^{-3}$、最多 $2000$ 步探索。该预算是初始配置，不保证达到某个误差。

**操作：**

1. 先训练约 $5$ 步，确认二阶导数和反向传播都能正常工作。
2. 固定训练坐标，使用三个初始化种子分别训练软、硬约束版本。
3. 两版使用同样的基础网络和优化器设置，记录实际耗时。相同迭代数不代表成本完全相同。
4. 在未用于训练的初值位置和边界时刻上测试；边界要覆盖整个 $[0,T]$。
5. 用独立内部配点测残差，再用约 $256\times41$ 的内部时空测试网格计算解误差。
6. 保存损失分项、模型参数和完整测试预测，方便重新绘图。
7. 选择一项消融：边界权重 $\lambda_b=0.1,1,10$，或内部配点数 $256,1024,4096$。每次只改变一个因素。

**图形：** 三项损失曲线；两端预测值随时间的曲线；预测解与误差的时空图；各时刻内部 RMSE。

**解释：** 软约束若方程残差小而边界误差大，说明损失平衡或边界采样不足；硬约束应使初边值误差接近数值舍入水平，但内部解误差仍取决于训练。三次初始化用于展示波动，不支持强统计结论。

为了定位问题，可以在训练前用解析解核验自动微分残差，并用有限差分检查少量参数方向导数。不要拿解析终态标签训练后又称为纯物理约束求解。

### 实验七：并行什么时候值得

**问题：** 吸收导致路径长度不同，怎样影响多进程或多线程效率？

**操作：**

1. 选择 R 多进程或 C++ OpenMP 中的一种作为主后端，另一种作为选做。
2. 固定网格、时间步和查询位置，取总样本量 $M=2^{12},2^{16},2^{20}$，并行度 $p=1,2,4$。
3. 将工作划成固定的 $64$ 个逻辑块，保证不同并行度执行同一组随机任务。
4. 按固定顺序归约贡献，核对数值结果；同时报告存活数和平均实际步数。
5. 单列进程池启动时间，核心时间包含任务传输、路径计算和汇总。
6. 预热后重复计时至少 $7$ 次，计算加速比 $S_p=t_1/t_p$ 和效率 $S_p/p$。
7. 可另设一个靠近边界的起点，保持其他条件不变，观察更短路径是否让并行开销更突出。

**图形：** 总耗时、加速比和并行效率对并行度；不同样本量分别画线。

**解释：** 小任务可能不值得启动进程；大任务也可能受到负载不均、随机数生成和归约的限制。先将每个后端与自身串行版本比较，再讨论不同语言的绝对成本。

### 综合比较：相同精度下再讨论效率

完成以上检查后，用解析基准做统一比较。可取 $N=64$，容差 $\varepsilon=10^{-2}$ 和 $10^{-3}$，分别查询一个内部点、八个分散的内部点，以及全部内部节点。

对每种方法扫描自己的预算：差分的时间步数、Monte Carlo 的路径数与合法网格、PINN 的训练预算。先检查误差，再比较达标配置的成本。随机法用独立批次调参，再换独立种子复验，避免选中一次幸运结果。

全场逐点 Monte Carlo 可能很昂贵，可以记录“当前预算内未达标或未完成”。没有必要为了凑齐每格结果而无限扩大实验。查询全场时，差分已有共享计算；Monte Carlo 不一定有同样优势。

PINN 分列训练、查询和二者之和。多时刻任务允许差分一次推进并保存中间结果，也允许网络一次训练后重复查询。只比较网络训练后的前向与差分完整求解，会遗漏实际成本。

## 第七章　怎样记录、计时和分析

### 7.1 内部误差和边界误差分开

主误差定义在内部查询点集合 $J$ 上：

$$
E_J=\sqrt{\frac1{|J|}\sum_{j\in J}(U_j-u_\star(x_j,T))^2}.
\tag{16}
$$

边界误差另报 $\max(|U_0|,|U_N|)$。对 PINN，报告覆盖整个测试时间段的采样时刻上的边界最大误差；它是离散检查结果，不是连续时间最大误差的严格上界。

这样可以避免将大量已知为零的边界测试点混入解误差，使指标显得过于乐观。若比较不同网格上的单点查询，应固定同一个物理位置，或明确计入插值。

对随机法，第 $\ell$ 批的空间均方误差记为 $L_\ell$，用

$$
\widehat E_J=\sqrt{\frac1R\sum_{\ell=1}^R L_\ell}
$$

汇总 $R$ 次独立运行。不要先对各批开方再平均后，将其当作同一个 RMSE 指标。

### 7.2 区分准备与实际计算

至少记录

$$
t_{\mathrm{total}}=t_{\mathrm{setup}}+t_{\mathrm{core}}.
$$

准备包括数组、卷积核、稀疏装配与分解；核心包括推进、抽样、回代、查询与必要归约。PINN 另外列训练时间和推理时间。编译、绘图、真值计算和正确性核验放在性能计时之外，实际随机数生成必须计入。

反复使用同一配置时可以复用矩阵分解或其他准备，但所有方法都应允许合理复用。一次性任务则计入全部准备。进程池启动单列，并报告包含启动的一次性总成本。

预热后重复测量至少 $7$ 次，保存原始时间，报告中位数和四分位范围。非常短的调用可多次连续执行后取平均，注明批量计时方式。硬件、浮点精度和线程限制保持一致。

### 7.3 原始记录应包含什么

每条记录至少保存：实验名、初值标识、$a,D,T,N,n$、方法、查询位置、重复编号、随机种子、误差、边界误差、准备与核心耗时。

Monte Carlo 增加路径数、存活数和实际步数；稀疏法增加装配、分解、回代和存储统计；PINN 增加网络结构、训练点数、损失权重、初始化、实际优化步数与终止原因。

环境信息包括操作系统、处理器、物理核心数、内存、软件版本、浮点精度和并行度。随机重复与计时重复解决不同问题，应分别保留。

### 7.4 怎样形成有解释力的结论

每项主要结论写清四件事：观察到的结果、能解释它的算法机制、结果适用的参数范围、尚未验证的部分。

例如：

> 四种显式实现在相同网格和步数下结果一致，而耗时随规模出现……差异。这说明当前收益主要来自……，没有改变数值误差。

> 增加路径数后，相对显式解的误差继续下降，而相对连续解的误差趋于……。网格加密使这一平台……，与离散偏差的解释一致。

> 边界附近的路径更早终止，降低了实际工作量，也使并行开销占比……。因此当前加速比应结合平均路径长度理解。

> 硬约束使初边值误差接近零，但内部精度仍随初始化变化。在本预算下，实际结果为……，不能由边界满足情况单独推断整体准确性。

没有加速也可以得到完整的计算机项目，关键是实现正确、比较公平，且能解释成本。理论上可能成立的优势，必须与本机实验观察分开写。

## 第八章　实施范围与交付

### 8.1 建议按四个阶段完成

1. **先做可靠的差分。** 完成端点处理、小网格检查、解析误差和网格加密。
2. **再做实现比较。** 加入三点卷积、Rcpp 和 RcppEigen，记录分阶段成本。
3. **加入随机与学习方法。** 实现逐步吸收、独立随机重复，以及 PINN 的初边值约束和测试。
4. **最后做性能实验。** 选择一种并行后端，完成同精度比较、图形和可复现记录。

最小完整项目保留：显式与稀疏隐式、吸收 Monte Carlo、PyTorch PINN、同模板实现比较，以及一种并行后端。二维、GPU、非零时变边界和第二种并行后端均为选做。

不要求将所有算法都用所有语言重写。可以由 Python 统一实验和绘图，Rcpp/Eigen 展示关键实现，R 多进程或 OpenMP 展示路径并行。

### 8.2 旧代码怎样处理

现有 `drift-diffusion-lab` 仍是旧边界方案的代码，**本次修订更新的是讲义，尚未同步改造该目录的求解器**。旧的运行命令和 `results/` 不能直接作为本方案的复现入口或结果。

需要同步改变的内容很具体：

- 将 $N$ 点环形网格改为含两端点的 $N+1$ 点网格。
- 将环绕读取改为内部切片和明确端点赋值。
- 将隐式接角矩阵改为内部普通三对角矩阵。
- 将只抽终点的随机方法改为逐步吸收游走。
- 将周期特征网络改为直接坐标网络和新的初边值约束。
- 更新初值、真值、误差指标、测试、参数和所有结果文件。

建议在独立目录逐步实现新版，保留旧代码作为学习参考，避免将两种问题的记录混在一起。第三章的显式示例可以作为起点，其余模块按本讲义补齐。

### 8.3 新实现的接口先统一

建议的接口约定是：输入初值数组、物理参数、终止时间和数值预算；输出包含端点的完整结果，或明确的查询结果。连续初值函数也应能替换，不能在求解器内部写死某一个基准。

可以按以下职责组织模块，名称只是建议：

- `problem.py`：模型参数、初值、解析基准与边界函数。
- `finite_difference.py`：显式、卷积和稀疏隐式求解器。
- `random_walk.py`：逐步吸收、随机流和路径统计。
- `pinn.py`：网络、损失、训练、保存与独立测试。
- `experiments.py`：参数扫描、原始记录和计时。
- `plot_results.py`：只读原始记录，生成报告图。
- `tests/`：边界、小网格、实现一致性和导数核验。

已有函数若接收了 `f_grid`，就应真正使用这份初值；需要连续函数时明确传入 `f`。PINN 硬约束中的初值也应与训练任务保持一致。

### 8.4 分工与报告

一人可主要负责差分、边界索引与稀疏实现，另一人主要负责吸收游走、并行和统一计时；PINN 与结果分析共同完成。两位成员都应能解释初边值问题和各方法的核心代码。

课程报告不超过八页，不必搬入整本讲义。优先展示：

- 一个边界和小规模正确性检查。
- 一组网格收敛和同算法实现比较。
- 一张吸收随机误差图。
- 一组 PINN 边界与内部误差结果。
- 一项并行规模实验与同精度成本比较。

详细扫描和额外图表留在仓库。README 写清安装、运行、测试、绘图、成员贡献、复用代码及 AI 使用情况。按 [课程要求](../../guisheng-dai/source/final-2026.md) 提供代码、原始记录、报告和展示材料。

## 选做：把边界改成非零值

基础方案完成后，可以将左端设为已知 $g_L(t)$，右端设为 $g_R(t)$，观察信号如何从边界进入区间。

这个扩展只需围绕明确的编程问题展开：显式使用旧时间层的端点；隐式将新时间层边界贡献加入右端；PINN 修改边界目标；随机路径触边后需要相应的边界收益规则，不能继续一律记零。

初值在两个端点应与 $g_L(0),g_R(0)$ 一致。建议先完成差分与 PINN 的扩展，随机方法的非零时变边界处理作为进一步选做，不必为它增加基础项目的数学负担。
